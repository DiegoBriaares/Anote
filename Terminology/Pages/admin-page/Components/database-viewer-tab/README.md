# Database Viewer Tab

**Component anchor:** `src/components/Admin/AdminPanel.tsx`

The **Database Viewer Tab** inspects selected raw database tables.

## Part Terms

- **Table Selector**: Chooses `roles` or `event_notes`.
- **Record Count**: Number of rows returned.
- **Raw Data Table**: Generic table built from returned row keys.
- **Raw Data Row**: One database row.
- **No Data State**: Empty table message.
