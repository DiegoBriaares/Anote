# Event Management Tab

**Component anchor:** `src/components/Admin/AdminPanel.tsx`

The **Event Management Tab** lists system events for admin review and deletion.

## Part Terms

- **User Filter**: Restricts events to one user or all users.
- **Events Table**: Tabular event listing.
- **Event Row**: One event record.
- **Event Selection Checkbox**: Adds/removes the row from Admin Selection.
- **Select/Deselect Action**: Text action for row selection.
- **Delete Event Action**: Deletes a single event.
- **Unimplemented Edit Action**: The current placeholder edit control.
