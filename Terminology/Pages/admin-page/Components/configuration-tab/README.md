# Configuration Tab

**Component anchor:** `src/components/Admin/AdminPanel.tsx`

The **Configuration Tab** edits globally visible product copy.

## Part Terms

- **Configuration Form**: Inputs for app title, console title, and subtitle.
- **Character Counter**: Limit feedback for each text field.
- **Live Preview**: Preview of the global Console Banner.
- **Save Changes Action**: Persists configuration.
- **Reset Action**: Reloads the saved configuration.
