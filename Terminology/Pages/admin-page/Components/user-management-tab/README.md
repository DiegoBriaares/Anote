# User Management Tab

**Component anchor:** `src/components/Admin/AdminPanel.tsx`

The **User Management Tab** lists registered users for admin review and deletion.

## Part Terms

- **Users Table**: Tabular user listing.
- **User Row**: One user record.
- **User Avatar Initial**: The generated initial circle.
- **Role Badge**: Shows `ADMIN` or `USER`.
- **Event Count Cell**: Shows the user's event count.
- **User Selection Toggle**: Adds/removes the row from Admin Selection.
- **Delete User Action**: Deletes a non-admin user.
- **Protected Admin Delete State**: Disabled delete control for admin users.
