# Admin Page

**Component anchor:** `src/components/Admin/AdminPanel.tsx`

The **Admin Page** is the admin-only control console for product text, users, events, and selected database tables.

## Page-Level Terms

- **Admin Header**: Back to Calendar action and tab navigation.
- **Admin Tabs**: The tab set for Config, Events, Users, and Database.
- **Admin Toast**: The transient success/error message.
- **Admin Selection**: The set of checked events or users.
- **Bulk Action Bar**: The floating action bar for deleting selected rows.

## Components

- **Admin Tabs**: Primary admin navigation.
- **Configuration Tab**: Edits global app banner text.
- **Event Management Tab**: Lists and deletes system events.
- **User Management Tab**: Lists and deletes users.
- **Database Viewer Tab**: Inspects selected raw tables.
- **Bulk Action Bar**: Executes destructive selection actions.
