# Identity Form

**Component anchor:** `src/components/Auth/Login.tsx`

The **Identity Form** collects credentials and submits either login or registration.

## Part Terms

- **Mode Switch**: The text button that toggles between login and registration.
- **Username Field**: The user identifier input.
- **Password Field**: The secret input.
- **Submit Action**: The primary action button. It starts a session in login mode and creates a user in registration mode.
- **Loading State**: The disabled button and spinner shown while the request is pending.
