# Authentication Page

**Component anchor:** `src/components/Auth/Login.tsx`

The **Authentication Page** is the unauthenticated entry page for starting or creating a session.

## Page-Level Terms

- **Identity Verification Surface**: The full-screen login/register page.
- **Authentication Mode**: The selected mode: login or registration.
- **Credential Error**: The error message returned by auth actions.

## Components

- **Identity Form**: The credential form and mode switch.
