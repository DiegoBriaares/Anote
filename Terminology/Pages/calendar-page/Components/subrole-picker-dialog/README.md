# Subrole Picker Dialog

**Component anchor:** `src/components/Calendar/SubrolesModal.tsx`

The **Subrole Picker Dialog** chooses a more specific note role when the selected role has subroles.

## Part Terms

- **Parent Role Header**: The selected role title.
- **Back to Roles Action**: Returns to the Role Picker Dialog.
- **Subrole Choice List**: The available subroles for the parent role.
- **Subrole Choice**: A selectable subrole label.
