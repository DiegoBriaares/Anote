# Role Note Workspace

**Component anchor:** `src/components/Calendar/NoteEnvironment.tsx`

The **Role Note Workspace** is the full-screen editor for event notes attached to a role or subrole.

## Part Terms

- **Note Context Header**: Shows event date, role, and event title.
- **Editor Pane**: The markdown textarea.
- **Preview Pane**: Rendered markdown view.
- **Attachment Sidebar**: File upload area and markdown support reminder.
- **Note Toolbar**: Preview toggle, attach file, insert link, and save controls.
- **File Open Popover**: Confirmation dialog for opening uploaded files.
- **Save Note Action**: Persists the role note.
