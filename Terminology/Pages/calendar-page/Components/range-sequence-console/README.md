# Range Sequence Console

**Component anchor:** `src/components/Input/RangeEventInput.tsx`

The **Range Sequence Console** is the Calendar Page modal for a multi-day Selection Window.

## Part Terms

- **Console Header**: The modal title and close action.
- **Quick Copy Panel**: The source-day event copy section at the top.
- **Source Selector**: Chooses the Source Day within the selected range.
- **Copy Candidate Row**: An existing source event that can be selected.
- **Sequence Row**: A per-day input row for creating new events across the range.
- **Event Draft Fields**: Title, hour, priority, link, and note inputs.
- **Execution Footer**: Status, cancel, and execute controls.
- **Execute Sequence Action**: Creates one event draft per selected day.
