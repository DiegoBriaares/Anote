# Day Visual Settings Dialog

**Component anchor:** `src/components/Calendar/DayConfigModal.tsx`

The **Day Visual Settings Dialog** edits visual context for one calendar day.

## Part Terms

- **Day Context Label**: Short text shown as the Daily Context Pill on the Month Board.
- **Day Background URL**: Image URL applied to the Day Cell.
- **Background Preview**: The local preview of the configured image.
- **Save Configuration Action**: Persists the context label and background image.
