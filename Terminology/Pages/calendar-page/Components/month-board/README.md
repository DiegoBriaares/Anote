# Month Board

**Component anchor:** `src/components/Calendar/MonthGrid.tsx`

The **Month Board** is one month inside the Calendar Workspace.

## Part Terms

- **Month Header**: The sector label, month title, and status dots.
- **Weekday Header**: The Sun-Sat row.
- **Day Cell**: A selectable calendar date.
- **Faded Day Cell**: A day from an adjacent month.
- **Today Cell**: The current date highlight.
- **Selected Cell**: A day inside the Selection Window.
- **Event Count Badge**: The small count for day events.
- **Event Chip**: A compact visual marker for a day event.
- **Time Priority Pill**: The small `HH:mm · P#` badge inside an Event Chip.
- **Ghost Event**: A comparison event from the user's own calendar while viewing a friend.
- **Daily Context Pill**: The day context label saved in Day Visual Settings.
- **Cell Background Image**: The configured image for a day cell.
