# Group Event Reader

**Component anchor:** `src/components/Calendar/GroupEventReader.tsx`

The **Group Event Reader** is the Calendar Page panel for reading the events across a Marked Day Set.

## Part Terms

- **Reader Header**: The title and selected day/event counts.
- **Day Event Column**: One selected day and its events.
- **Day Event Count**: The per-day event count badge.
- **Readable Event Card**: A single event summary with title, hour, priority, completion state, link, and note.
- **Empty Day State**: The no-events placeholder for a selected day.
