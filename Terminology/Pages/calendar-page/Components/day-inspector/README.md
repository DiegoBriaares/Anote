# Day Inspector

**Component anchor:** `src/components/Calendar/DayModal.tsx`

The **Day Inspector** is the modal opened from a day cell to inspect events and enter note workflows.

## Part Terms

- **Selected Day Header**: The date title and modal actions.
- **Order Control**: Sorts events by hour or priority.
- **Open Day Administration Action**: Opens the Day Events Administration Page for the selected date.
- **Configure Day Visuals Action**: Opens the Day Visual Settings Dialog.
- **Event Inspection List**: The scrollable list of events for the day.
- **Inspectable Event Card**: A day event row that can open role note selection when editable.
- **Read-Only Badge**: Indicates friend calendar mode.
- **Event Metadata Row**: Hour, priority, completion state, note, and link information.
