# Friends Page

**Component anchor:** `src/components/Friends/SocialPanel.tsx`

The **Friends Page** manages friend connections and launches read-only friend calendars.

## Page-Level Terms

- **User Network Header**: The page header and friend-view explanation.
- **Social Error Banner**: Displays connection or access failures.
- **Friend Calendar Return Action**: Returns from a friend calendar to the user's own calendar.

## Components

- **Friends List**: Current connections and friend calendar actions.
- **User Directory**: All visible users and add-friend actions.
