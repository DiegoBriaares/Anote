# Profile Page

**Component anchor:** `src/components/Profile/ProfilePanel.tsx`

The **Profile Page** edits user identity and appearance preferences.

## Page-Level Terms

- **Profile Control Header**: The page header and back action.
- **Visual Preferences Panel**: The main settings card.
- **Profile Actions Row**: Reset and save controls.

## Components

- **Profile Settings Panel**: Username, background, accent, overlay, and theme controls.
