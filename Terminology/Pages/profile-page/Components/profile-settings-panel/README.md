# Profile Settings Panel

**Component anchor:** `src/components/Profile/ProfilePanel.tsx`

The **Profile Settings Panel** controls personal display preferences.

## Part Terms

- **Username Field**: Edits the visible username.
- **Background Image Field**: Stores the shell background URL.
- **Accent Picker**: Color input for avatar and accent variables.
- **Accent Hex Field**: Text form of the accent color.
- **Noise Overlay Toggle**: Enables or disables texture overlay preference.
- **Theme Selector**: Switches between light and dark themes.
- **Reset Preferences Action**: Reverts local changes to saved profile values.
- **Save Preferences Action**: Persists profile settings.
