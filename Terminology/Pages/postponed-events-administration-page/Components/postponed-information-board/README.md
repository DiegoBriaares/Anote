# Postponed Information Board

**Component anchor:** `src/components/Calendar/PostponedEventsInformation.tsx`

The **Postponed Information Board** gives read-only history for postponed events in the active View Scope.

## Part Terms

- **Information Header**: Board title and postponed context.
- **Information Event Card**: A read-only postponed event row.
- **Track Record Toggle**: Expands origin dates for a postponed event.
- **Track Record Panel**: Shows origin dates.
- **Original Entry State**: The message shown when no origin dates exist.
