# Postponed Event Board

**Component anchor:** `src/components/Calendar/PostponedEventBoard.tsx`

The **Postponed Event Board** is the editable board for events in postponed storage.

## Part Terms

- **Scope Switcher**: Toggles between `This week events` and `All events`.
- **Order Control**: Sorts postponed events by hour or priority.
- **Postponed Event List**: The scoped list of postponed events.
- **Postponed Event Card**: One postponed event with metadata and actions.
- **Postponed Draft Form**: Title, hour, priority, link, and note inputs.
- **Save Entry Action**: Adds or updates a postponed event.
