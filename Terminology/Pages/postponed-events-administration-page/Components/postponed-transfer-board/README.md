# Postponed Transfer Board

**Component anchor:** `src/components/Calendar/PostponedRangeBoard.tsx`

The **Postponed Transfer Board** transfers events out of or within postponed storage.

## Part Terms

- **Transfer Mode Control**: Chooses copy or move.
- **Source Event List**: Postponed events in the active View Scope.
- **Transfer Candidate Row**: A selectable postponed event.
- **Target Panel**: Destination controls.
- **Target Date Field**: Calendar day destination for restoring postponed events.
- **Target Postponed View Control**: Destination scope for moving between postponed buckets.
- **Copy/Move Selected Action**: Transfers selected postponed events to the Target Day.
- **Copy/Move to Postponed Action**: Transfers selected postponed events to another View Scope.
