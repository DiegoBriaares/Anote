# Roles Page

**Component anchor:** `src/components/Roles/RolesPanel.tsx`

The **Roles Page** maintains role and subrole labels used by Role Notes.

## Page-Level Terms

- **Roles Dashboard Header**: The page header and purpose text.
- **Role Control Area**: The main area for creating, ordering, renaming, and deleting roles.

## Components

- **Roles List**: Ordered role list with nested subroles.
