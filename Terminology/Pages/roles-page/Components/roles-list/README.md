# Roles List

**Component anchor:** `src/components/Roles/RolesPanel.tsx`

The **Roles List** is the ordered set of note roles.

## Part Terms

- **Add Role Action**: Creates a role label.
- **Role Row**: One role entry.
- **Role Order Controls**: Up/down actions that change display order.
- **Role Color Dot**: The role's color indicator.
- **Rename Role Action**: Clicking the role label to rename it.
- **Add Subrole Action**: Creates a child label under a role.
- **Delete Role Action**: Removes a role.
- **Subrole List**: Nested subroles under a role.
- **Subrole Row**: One child role entry.
- **Rename Subrole Action**: Clicking a subrole label to rename it.
- **Delete Subrole Action**: Removes a subrole.
