# Console Banner

**Component anchor:** `src/App.tsx`

The **Console Banner** is the global brand and context header shown above active pages.

## Part Terms

- **Console Title**: The small uppercase label from `appConfig.console_title`.
- **Application Title**: The large product title from `appConfig.app_title`.
- **Application Subtitle**: The short descriptive line from `appConfig.app_subtitle`.
- **Accent Line**: The visual divider under the subtitle.
- **Banner Configuration**: The admin-editable data source for the three text fields.
