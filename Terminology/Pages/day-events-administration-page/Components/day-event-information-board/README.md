# Day Event Information Board

**Component anchor:** `src/components/Calendar/DayEventsInformation.tsx`

The **Day Event Information Board** gives read-only context for events on the Active Administration Date.

## Part Terms

- **Information Header**: Board title and active date.
- **Information Event Card**: A read-only event row.
- **Track Record Toggle**: Expands transfer history for an event.
- **Track Record Panel**: Shows origin dates and postponed status.
- **Original Entry State**: The message shown when no origin dates exist.
- **Previously Postponed Badge**: Marks events restored from postponed storage.
