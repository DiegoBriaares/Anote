# Day Event Board

**Component anchor:** `src/components/Calendar/EventBoard.tsx`

The **Day Event Board** is the editable board for events on the Active Administration Date.

## Part Terms

- **Board Header**: Board title, active date, order control, and read-only badge.
- **Order Control**: Sorts events by hour or priority.
- **Action Error Banner**: Displays failed event operations.
- **Day Event List**: The sorted list of events for the active date.
- **Day Event Card**: One event with title, hour, priority, note, link, and actions.
- **Completion Action**: Marks an event complete or active.
- **Edit Action**: Loads the event into the Event Draft Form.
- **Delete Action**: Removes the event.
- **Event Draft Form**: Title, hour, priority, link, and note inputs.
- **Save Entry Action**: Adds a new event or saves edited event changes.
