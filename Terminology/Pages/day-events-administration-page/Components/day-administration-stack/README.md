# Day Administration Stack

**Component anchor:** `src/components/Calendar/DayAdministration.tsx`

The **Day Administration Stack** arranges all boards used to administer the Active Administration Date.

## Part Terms

- **Administration Section Title**: The local "Administration" heading.
- **Management Mount Delay**: The short remount delay used so the Range Transfer Board resets cleanly when the date changes.
- **Board Stack**: The vertical order: Day Event Board, Day Event Information Board, then Range Transfer Board.
