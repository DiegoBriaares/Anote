# Range Transfer Board

**Component anchor:** `src/components/Calendar/RangeBoard.tsx`

The **Range Transfer Board** manages events across the current Selection Window from inside the Day Events Administration Page.

## Part Terms

- **Window Label**: The selected date range.
- **Source Selector**: Chooses which day in the Selection Window provides events.
- **Transfer Mode Control**: Chooses copy or move.
- **Source Event List**: Events available from the Source Day.
- **Transfer Candidate Row**: A selectable source event.
- **Target Panel**: Destination controls for target date and postponed view.
- **Target Date Field**: Calendar day destination for copy/move.
- **Target Postponed View Control**: Chooses `This week events` or `All events` when postponing.
- **Select All Action**: Selects or clears all source events.
- **Copy/Move Selected Action**: Transfers selected events to the Target Day.
- **Copy/Move to Postponed Action**: Transfers selected events into postponed storage.
